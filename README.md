# Student Registration - Windows Forms

A simple student registration application developed using C# and Windows Forms as a university coursework project.

## Features

- Enter student names and student numbers.
- Add student records to a list.
- Display registered students using a ListBox.
- Validate input fields and show a warning when required information is missing.
- Clear input fields after successful registration.

## Technologies

- C#
- Windows Forms
- .NET Framework
- Visual Studio

## Notes

Student records are stored in memory using a List and are not saved permanently. All records are cleared when the application closes.

This project was developed for educational purposes. The university logo is used as part of the coursework and does not imply official endorsement.
